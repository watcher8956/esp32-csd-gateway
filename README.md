# ESP32 CSD Gateway

Шлюз GSM CSD–TCP на базе ESP32. Устройство позволяет устанавливать CSD-соединения через GSM-модемы, используя TCP в качестве интерфейса для клиентских приложений.

Один шлюз работает с двумя независимыми модемами и SIM-картами. Несколько шлюзов при необходимости можно объединить в общий пул с автоматическим выбором свободной линии.

## Как это работает

Клиент подключается к одному из TCP-портов шлюза по Wi-Fi и отправляет номер телефона первой строкой. ESP32 передаёт команду набора соответствующему GSM-модему.

После установления CSD-соединения шлюз начинает передавать данные между TCP-клиентом и модемом в обоих направлениях. Соединение завершается при отключении клиента, потере несущей или срабатывании таймаута простоя.

Для работы с несколькими устройствами предусмотрен дополнительный режим координации. Один из шлюзов выполняет роль дирижёра: принимает клиентские подключения, отслеживает состояние SIM-карт и выбирает свободную линию. Остальные устройства подключаются к нему в качестве агентов.

## Возможности

- Два независимых CSD-канала на одной ESP32.
- TCP-интерфейс для установления и передачи данных.
- Работа с несколькими GSM-модемами и профилями их поведения.
- Настройка параметров через Serial-консоль.
- Сохранение настроек в энергонезависимой памяти ESP32 (NVS).
- Объединение до 16 шлюзов в общий пул (до 32 SIM-карт).
- Автоматический поиск дирижёра по UDP.
- Linux-стенд для тестирования без физического оборудования.

## Аппаратная часть

Основой устройства служит ESP32 DevKit V1 с двумя подключёнными GSM-модемами.

Используемые последовательные интерфейсы:

| Интерфейс | RX ESP32 | TX ESP32 | Скорость |
|---|---:|---:|---:|
| UART1 (SIM1) | GPIO25 | GPIO26 | 9600 |
| UART2 (SIM2) | GPIO16 | GPIO17 | 9600 |
| UART0 (USB) | GPIO3 | GPIO1 | 115200 |

UART0 используется для подключения к Serial Monitor и вывода диагностических сообщений.

Фотографии устройства, схемы подключения и другие материалы аппаратной части находятся в каталоге `hardware/`.

## Прошивка

Прошивка написана для Arduino IDE с использованием ESP32 Arduino Core.

Основные файлы:

| Файл | Описание |
|---|---|
| `esp32_csd_gateway.ino` | Инициализация оборудования, Wi-Fi и задач шлюза |
| `gw_core.hpp` | Основная логика CSD-сессии и передачи данных |
| `gw_params.hpp` | Настройки, NVS и Serial-консоль |
| `gw_director.hpp` | Координация нескольких шлюзов |

### Настройка устройства

Настройки можно изменять через Serial Monitor на скорости 115200 бод.

Основные команды:

| Команда | Назначение |
|---|---|
| `help` | Список команд |
| `show` | Текущие параметры |
| `set <ключ> <значение>` | Изменение параметра |
| `save` | Сохранение параметров |
| `wifi` | Подключение к Wi-Fi |
| `reboot` | Перезагрузка |
| `reset` | Сброс настроек |

Настройки сохраняются в NVS и не теряются после отключения питания.

### TCP-порты

По умолчанию используются следующие порты:

| Порт | Назначение |
|---|---|
| 5000 | Канал SIM1 |
| 5001 | Канал SIM2 |
| 5010 | Связь агентов с дирижёром |
| 5020 | Клиентский порт общего пула |

Номера портов можно изменить через параметры устройства.

## Тестирование под Linux

Для проверки логики шлюза предусмотрен отдельный испытательный стенд.

Linux-версия использует те же `gw_core.hpp` и `gw_director.hpp`, что и прошивка ESP32. Вместо GSM-модемов используются псевдотерминалы (PTY), к которым подключается Python-эмулятор SIM800L.

Тесты проверяют установление соединений, передачу данных, обработку отказов модема, одновременные вызовы и работу пула шлюзов.

### Запуск тестов

Необходимы:
- Linux;
- Python 3;
- GCC/G++ с поддержкой C++17.

Из корневой папки проекта:

```bash
python3 tests/run_tests.py
```

Скрипт собирает Linux-версию шлюза и запускает набор автоматических испытаний.
